# Maina's Pishori: bulk order landing page

Single-page site for 100% pure Mwea Pishori rice (KSh 180 per kg). All orders go to WhatsApp: +254 794 372 117.

## Files
- `index.html`: the whole page (HTML, CSS, JavaScript, Sikat font and both photos are inside it)
- `.nojekyll`: tells GitHub Pages to serve the file as it is

## Publish on GitHub Pages
1. Create a free account at github.com, then click **New repository**. Name it `mainas-pishori` and set it to **Public**.
2. Click **uploading an existing file** and drag in `index.html` and `.nojekyll` (unzip first). Click **Commit changes**.
3. Go to **Settings > Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**, choose branch `main` and folder `/ (root)`, then **Save**.
4. After 1 to 2 minutes your site is live at `https://YOUR-USERNAME.github.io/mainas-pishori/`.

## Change the price or phone number
Open `index.html` in a text editor. Search for `180` (price) and `254794372117` (WhatsApp number) and change them, then upload the file again.
